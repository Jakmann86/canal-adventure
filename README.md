# canal-adventure
Point and Click Maths Canal Adventure Game

- **[`game/`](game/)**: the playable game (Vite + TypeScript). See [`game/README.md`](game/README.md) for how to run it, the route and puzzles, and the code layout.
- **[`project/`](project/)**: the original Claude Design mockups the art and interface are based on (`Canal Adventure Scenes.dc.html`).
- **[`chats/`](chats/)**: the design conversation behind those mockups.

```sh
cd game
npm install
npm run dev   # http://localhost:5173
```
